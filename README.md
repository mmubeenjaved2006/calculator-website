## 📖 About the Project

Calculator is a modern frontend web application designed to perform basic mathematical calculations through an intuitive and responsive interface.

The application focuses on simplicity, usability, and responsive web design, providing a smooth experience across desktop, tablet, and mobile devices.

This project demonstrates practical skills in JavaScript programming, DOM manipulation, event handling, and frontend development.

## ✨ Key Features

- 🧮 Basic arithmetic operations
- ➕ Addition, subtraction, multiplication, and division
- 🔢 Interactive number and operator buttons
- 🧹 Clear and reset functionality
- 📱 Responsive layout for mobile, tablet, and desktop
- 🎨 Modern and user-friendly interface
- ⚡ Fast and lightweight performance
- 🖥️ Real-time calculator display updates
- 🌐 Browser-based application

## 💻 Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/mmubeenjaved2006/Calculator.git
```

### 2. Navigate to the Project Directory

```bash
cd Calculator
```

### 3. Run the Application

Open `index.html` in your preferred web browser.

Alternatively, use the Live Server extension in Visual Studio Code.

No additional packages or dependencies are required.

## ⚙️ How It Works

1. Open the calculator application.
2. Enter numbers using the calculator buttons.
3. Select an arithmetic operator.
4. Enter another number.
5. Press the equals button to calculate the result.
6. Use the clear button to reset the calculator.
